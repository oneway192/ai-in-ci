# Паспорт эксперимента ЛР 1 — вариант 7

Дата: 2026-09-24 14:18:56 UTC

## Цель и критерии

**Вариант 7. Контекст:** бумажная текстура (подложка макета). **Фактор:** увеличение размера изображения с 96×96 до 144×144 (×1,5).

**Цель:** проверить воспроизводимость генератора и определить, обнаруживается ли влияние изменения размера на четыре метрики: среднюю яркость, контраст, граничную энергию и энтропию.

**Гипотеза:** увеличение размера изображения с 96×96 до 144×144 при неизменных остальных параметрах не приведёт к существенному изменению средней яркости, контраста, граничной энергии и энтропии относительно межseedового разброса.

Гипотеза, критерий существенности `|Δ| > 2·s_base` и практический порог контраста `0.15` зафиксированы до основного запуска в [конфигурации варианта](../../configs/variant_07.json) и [журнале](../../reports/journal.md).

Внешние входные данные отсутствуют: синтетические изображения создаются учебным генератором `lab01_generator.py`, версия `1.0`. Используется только стандартная библиотека Python, сторонние пакеты не используются.

- `lab01_experiment.py`: `69257206dab50ef35de448b45764daad0d4f60dbc98febd8953c6faee28e06b5`.

## Параметры и процедура

Базовые параметры: `size = 96`, `cell = 4`, `octaves = 3`, `persistence = 0.6`, `quantize = 8`, `interp = smooth`. В факторной серии изменён только `size = 144`; остальные параметры сохранены.

Базовый seed — `101`; для оценки разброса использована серия `101–105`, `n = 5`. Протокол воспроизводимости: `101, 101, 1101, 101`.

Фактически использованная команда из каталога `LR01-1`:

```powershell
python src\lab01_experiment.py --variant 7 --out artifacts\v07
```

В [демонстрации типовой ошибки](../../reports/error_demo.md) два запуска без seed дали разные массивы пикселей; после фиксации `--seed 101` контрольные суммы совпали.

## Ограничения

- `n = 5` — небольшая серия для оценки разброса.
- Исследован один контекст текстуры и один фактор.
- Критерий `|Δ| > 2·s_base` является учебным правилом, а не полноценным статистическим тестом.
- Отсутствие обнаруженного эффекта не доказывает его полного отсутствия.
- Четыре метрики характеризуют статистические свойства яркости, но не дают полной оценки эстетического качества или реальной читаемости текста.
