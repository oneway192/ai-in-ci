# Демонстрация ошибки воспроизводимости

## Запуск без фиксированного seed

Два запуска генератора выполнены без параметра `--seed`. Скрипт выбрал seed из системного времени, поэтому полные массивы пикселей различаются.

| Запуск | seed | SHA-256 массива пикселей |
| ---: | ---: | --- |
| 1 | 18649652 | `6a6289586e9466726cff5b49bb1a8c45386ea7c3c62f59017b3b02c156e74f0a` |
| 2 | 1396468852 | `c366c933daa70824e593939edeb302372c172d2ac3585077ae857a492f354f16` |

**Симптом:** одинаковая команда даёт разные изображения и разные контрольные суммы.

**Причина:** seed не зафиксирован; генератор использует значение, полученное из системного времени.

## Исправление

Запуск повторён дважды с `--seed 101`.

| Запуск | seed | SHA-256 массива пикселей |
| ---: | ---: | --- |
| 1 | 101 | `93fae5913d79728429ddcdf533063672739fd51e5afa6a7ac243e3e6a80d290b` |
| 2 | 101 | `93fae5913d79728429ddcdf533063672739fd51e5afa6a7ac243e3e6a80d290b` |

После фиксации seed отпечатки совпали. Для воспроизводимого эксперимента seed необходимо явно задавать и сохранять в паспорте.
