# Журнал эксперимента

## 24.09.2026 - подготовка

Подготовлена изолированная среда Python. Для генератора используются только модули стандартной библиотеки. Зафиксированы Python 3.12.0, CPython, Windows 11 и zlib 1.2.13.

### Гипотеза, записанная до запуска

Увеличение размера бумажной текстуры в 1,5 раза - с 96×96 до 144×144 пикселей - при неизменных остальных параметрах не приведёт к существенному изменению средней яркости, контраста, граничной энергии и энтропии относительно естественного разброса между seed.

Учебный критерий существенности: `|Δ| > 2·s_base`. Дополнительный практический порог контраста для малозаметной подложки под мелким текстом: `0.15`.

## Проверка типовой ошибки

Генератор дважды запущен без `--seed`: получены разные seed и разные SHA-256 массива пикселей. После двух запусков с `--seed 101` SHA-256 совпали. Подробности находятся в [error_demo.md](error_demo.md).

## Основной эксперимент

Команда:

```powershell
python src\lab01_experiment.py --variant 7 --out artifacts\v07
```

Основной запуск сохранён с датой `2026-09-24 14:18:56 UTC`.

Протокол воспроизводимости:

```text
EQ_1_2 = true
EQ_1_4 = true
EQ_1_3 = false
EQ_2_4 = true
```

Для серии `seed 101…105` ни одна из четырёх метрик не превысила порог `|Δ|/s_base > 2`. Максимальное отношение составило 0.32 для энтропии. Средний контраст изменился с 0.1394 до 0.1390 и в обеих сериях остался ниже практического порога 0.15.

**Вывод:** при `n=5` существенного влияния увеличения размера 96→144 на исследуемые статистики не обнаружено; исходная гипотеза не опровергнута.


## 26.09.2026 — часть Б: рабочая область Engee

Работа выполнена в веб-среде Engee.

Зафиксированные версии:

- Engee: `26.9.2-H1`
- версия личного кабинета: `v26.9.1.1`
- Julia: `1.12.4`
- ОС вычислительной среды: `Linux (x86_64-linux-gnu)`
- CPU: `112 × Intel(R) Xeon(R) Platinum 8180 CPU @ 2.50GHz`

В каталоге `/user/ai-in-ci/LR01/` создан и сохранён скрипт `LR01_environment.ngscript`.

В одной ячейке выполнены команды `VERSION` и `versioninfo()`.

Для проверки состояния рабочей области выполнено присваивание `seed = 101`.

После выполнения переменная `seed` появилась в панели «Переменные» со значением `101` и классом `Int64`.

После действия «Очистить все переменные» рабочая область стала пустой.

После действия «Перезапуск ядра» рабочая область также осталась пустой.
