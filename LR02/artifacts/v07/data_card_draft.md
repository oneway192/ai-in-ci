# Паспорт набора данных (заготовка, разделы по Gebru и др., 2018)

Сценарий использования: обложки подкастов (публикация в сети, монетизация).

## 1. Motivation (мотивация)

Набор создан для учебного анализа происхождения и лицензий материалов, предназначенных для обложек монетизируемых подкастов. Пользователи набора в рамках сценария — автор подкаста, дизайнер обложек и ответственный за проверку прав. Данные синтетические и не предназначены для фактической публикации как реальные материалы.

## 2. Composition (состав)

* Число объектов: 12; по типам: audio — 4, text — 4, image — 4.
* Распределение лицензий: CC0-1.0 — 4, CC-BY-NC-SA-4.0 — 2, MIT — 2, CC-BY-NC-4.0 — 2, Apache-2.0 — 2.
* Объектов с персональными данными: 0.
* Объектов, для которых лицензия требует указания авторства: 8 (список авторов нужно публиковать вместе с набором).
* Результаты аудита: ошибок — 4, предупреждений — 1.

## 3. Collection Process (процесс сбора)
* Даты получения: 2026-01-02 … 2026-08-13.
* Источники: example.org.

Двенадцать записей детерминированно созданы скриптом преподавателя `lab02_make_variant.py` для варианта 7. Домены, правообладатели, имена файлов и контрольные суммы учебные и вымышленные; фактические материалы не загружались. В манифесте персональные данные отсутствуют, поэтому поле согласия имеет значение `n-a`.

## 4. Preprocessing/cleaning/labeling (обработка и разметка)

По результатам аудита item01, item04, item08 и item09 решено исключить из коммерческого сценария либо держать в карантине до получения отдельного коммерческого разрешения. Для item01 и item10 обнаружено совпадение контрольной суммы при разных лицензиях; обе записи помещаются в карантин до проверки первоисточника, после чего в рабочей версии должна остаться одна подтверждённая запись. Исходный манифест сохранён без изменения; разметка объектов не выполнялась.

## 5. Uses (использование)
* Предполагаемое: обложки подкастов (публикация в сети, монетизация); коммерческое использование — да; производные — да.

Набор в исходном виде не подходит для коммерческой публикации обложек, поскольку содержит материалы с условием NonCommercial и дубликат с противоречивыми сведениями о лицензии. Он также не подходит для реального производства без проверки заявленных лицензий по первоисточникам. Автоматический аудит является учебной проверкой и не юридической консультацией.

## 6. Distribution (распространение)
* Публикация набора — предполагается; условия зависят от лицензий объектов (раздел 2).

Производные допустимо передавать на тех же условиях, однако это не устраняет запрет коммерческого использования для лицензий с NonCommercial. Для объектов, лицензия которых требует атрибуции, вместе с публикацией должен поддерживаться список правообладателей. До устранения ошибок и проверки дубликата публиковать исходный набор как пригодный для сценария нельзя.

## 7. Maintenance (сопровождение)

Ответственный за сопровождение и канал для запросов об удалении в исходных данных не указаны — это документированный пробел. До практического использования нужно назначить ответственного, определить канал запросов и вести версию манифеста с журналом исключений, разрешений и повторных аудитов.
