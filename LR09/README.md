# ЛР №9. Промпт-инжиниринг

**Вариант 7:** контекст №2 — обложка подкаста о городе; элемент №1 — стилевая фраза `minimal flat geometric style`; seed 101…105.

Цель работы — проверить экспериментом, как один добавленный элемент запроса меняет результат генератора изображений, и сравнить три приёма запроса к языковой модели по заданной схеме ответа.

| Параметр | Фактическое значение |
| --- | --- |
| Часть 1 | SD Turbo на закреплённой ревизии, 1 шаг, guidance 0, 512×512, `float32`, процессор; метрики — CLIP ViT-L/14, `edge`, `contrast` |
| Запросы | A: `podcast cover about the city`; B: тот же запрос и `, minimal flat geometric style` |
| Часть 2 | Perplexity, веб-версия, бесплатный аккаунт, режим по умолчанию, модель неизвестна, 06.11.2026; три приёма по три повтора, новый чат на повтор |
| Среда | Google Colab, процессор, Python 3.13.18 |
| Библиотеки | torch 2.11.0+cpu; diffusers 0.42.1; transformers 5.22.0; numpy 2.4.6; Pillow 11.3.0 |
| Итог | все четыре изменения больше допуска, но по 2s значимо только `contrast`; ярусы горизонта на 4 из 5 seed против 0 из 5; приёмы части 2 не различаются |

## Как повторить

1. Открыть [lab09.ipynb](lab09.ipynb) в Google Colab, среда без GPU. Методичка называет средой Engee, снимков консоли не требует; библиотека считает на процессоре.
2. Выполнить ячейки сверху вниз. Ноутбук удаляет несовместимый `torchao`, записывает библиотеки ячейками `%%writefile` и сверяет их SHA-256, выполняет демо-вариант и вариант 7.
3. После просмотра листов заполнить `VISUAL_CHECK`. Ответы языковой модели записаны в ноутбуке ячейками `%%writefile` и лежат в `answers/`; для новых ответов отправить запросы из `prompts/`, каждый в новом чате.
4. Выполнить ячейки до конца; последняя скачивает архив результатов.
