# ЛР №3. Подготовка изображений и визуализация в Engee

**Вариант 7** — низкоконтрастная сцена, квантование яркости до 4 бит.

| | |
| --- | --- |
| Среда сохранённого прогона | Engee `26.9.2-H4`, Julia `1.12.4` |
| Сцена | `128×128`, `RGB{Float64}`, seed `101` |
| Серия | seed `101:105` |
| Критерий | `|Δ| > 2·s`; практический допуск: изменение метрики более 5 % или средний PSNR ниже 30 dB |
| Результат | SHA-256 воспроизведён; все три метрики статистически значимы; практически значимы изменения контраста и энтропии |

## Результат

| Метрика | База | `s` | После | Δ | `abs(Δ)/s` | Стат. значимость |

| Средняя яркость | 0.49196585 | 8.38856e-5 | 0.49291341 | +0.00094756 | 11.30 | да |

Средний PSNR по seed `101:105` равен `33.51000167578998 dB`. Средняя яркость изменилась на `+0.1926 %` и осталась в допуске 5 %. Контраст изменился на `+48.2962 %`, энтропия — на `-38.7968 %`; оба изменения практически существенны по заранее записанному допуску.

## Как повторить

Работа выполнялась в Engee. Оригинальный `.ngscript` из Engee скачать нельзя, поэтому в репозитории сохранены экспортированные notebook-файлы HTML и PDF, а поддельный `.ngscript` не создавался.

Для повторного запуска в Engee нужно загрузить [src/lab03_lib.jl](src/lab03_lib.jl), выполнить `include("lab03_lib.jl")` из каталога LR03 и повторить ячейки, сохранённые в [reports/LR03_07.html](reports/LR03_07.html).
