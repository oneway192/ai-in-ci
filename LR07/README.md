# ЛР №7. Построение автокодировщика

**Вариант 7:** набор сцен №2 `disc_rect` — «диск и полоса» (4 фактора сцены); фактор №1 — размер латентного вектора, d = 8 → 2; seed 101…105.

Цель работы — построить свёрточный автокодировщик на синтетических сценах, измерить качество реконструкции на тестовой выборке и выяснить экспериментом, что теряется при слишком узком латентном векторе.

| Параметр | Фактическое значение |
| --- | --- |
| Модель | свёрточный автокодировщик `ConvAE` из `lab07_lib.py` |
| Данные | синтетические сцены 3×32×32, 4096 обучающих и 1024 тестовых, seed данных 7 |
| Режимы | A: d = 8; B: d = 2; оба — MSE, Adam 2·10⁻³, пакет 128, 20 эпох |
| Среда | Google Colab, Tesla T4, Python 3.13.16 |
| Библиотеки | torch 2.11.0+cu130; numpy 2.1.3; Pillow 11.3.0 |
| Итог | гипотеза подтверждена: PSNR −5,59 дБ, радиус диска и положение полосы теряются |

- Эталон «средняя картинка» — 16,89 дБ: выигрыш режима A +9,30 дБ, режима B +3,71 дБ.
- В режиме B диск восстанавливается размытым пятном почти одного размера, а полоса превращается в ленту по всей ширине: радиус и положение полосы потеряны.
- Развёртка по d (seed 101–103): 19,42 / 20,60 / 22,08 / 22,98 / 26,01 дБ при d = 1, 2, 3, 4, 8; при d = 4 обучение нестабильно (21,7–25,2 дБ по seed).

- Демонстрационный вариант 1 воспроизведён: PSNR 26,01 → 23,19 дБ (в методичке 26,00 → 23,20), эталон 17,171 дБ совпал.

## Как повторить

1. Открыть [lab07.ipynb](lab07.ipynb) в Google Colab и выбрать среду «Графический процессор T4». На процессоре одно обучение идёт около 5 минут, серию на нём не запускают.
2. Выполнить ячейки сверху вниз. Ноутбук сам записывает библиотеки из `src/` ячейками `%%writefile` и сверяет их SHA-256, выполняет демо-вариант и вариант 7 и сохраняет `artifacts/` и `reports/environment.txt`.
3. После просмотра листа сравнения заполнить `VISUAL_CHECK` и выполнить ячейки до конца; последняя скачивает `lab07_results.zip`.
4. Обучение на GPU не побитово детерминировано: значения воспроизводятся в пределах разброса между seed, а не до последнего знака.
