# Искусственный интеллект в креативных технологиях

Лабораторные работы по курсу. Каждая работа находится в отдельном каталоге
и содержит исходный код, параметры эксперимента, полученные артефакты и отчёты.

## Работы

| № | Тема | Вариант | Результат |
| --- | --- | --- | --- |
| 01 | Запуск открытой модели text-to-image | 6 — постер для медиалаборатории | два запуска, SHA-256 совпали |

## Структура

```text
LR0N/
├── README.md       описание работы и запуск
├── src/            исходный код
├── configs/        параметры эксперимента
├── artifacts/      результаты и manifest.json
├── reports/        окружение, журналы и проверки
```

## Общие правила

1. Параметры эксперимента хранятся отдельно в `configs/`.
2. Рядом с результатами сохраняются манифесты с параметрами запуска.
3. Версия модели и её ревизия фиксируются.
4. Веса моделей, кэш и виртуальные окружения в репозиторий не добавляются.
5. Ошибки и результаты проверок сохраняются в `reports/`.
