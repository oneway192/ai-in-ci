## Структура

```text
LR0N/
├── README.md       описание работы и воспроизведение
├── src/            исходный код / учебные библиотеки
├── artifacts/      фактические результаты
├── reports/        отчёт, журнал, среда и подтверждения
├── configs/        параметры, если нужны работе
├── data/           входные данные, если нужны работе
├── *.ipynb         выполненный notebook с outputs, если предусмотрен работой
└── requirements.txt  зависимости, если работа имеет своё Python-окружение
```

```README.md```, ```src/```, ```artifacts/``` и ```reports/``` являются базовой структурой. Остальные элементы создаются только по требованиям конкретной лабораторной.

Notebook включается только в те лабораторные, где он предусмотрен методичкой или фактическим сценарием выполнения.

## Общие правила

1. Параметры эксперимента хранятся отдельно в `configs/`.
2. Рядом с результатами сохраняются манифесты с параметрами запуска.
3. Версия модели и её ревизия фиксируются.
4. Веса моделей, кэш и виртуальные окружения в репозиторий не добавляются.
5. Ошибки и результаты проверок сохраняются в `reports/`.
