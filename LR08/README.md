# ЛР №8. Генерация и интерполяция в латентном пространстве

**Вариант 7:** набор сцен №2 `disc_rect` — «диск и полоса» (4 фактора сцены); фактор №1 — вес KL-члена, β = 1 → 8; seed 101…105.

Цель работы — построить вариационный автокодировщик на синтетических сценах, получить из него сэмплы и промежуточные сцены и выяснить экспериментом, как вес KL-члена влияет на реконструкцию, интерполяцию, сэмплы и связь латентных осей с факторами сцены.

| Параметр | Фактическое значение |
| --- | --- |
| Модель | вариационный автокодировщик `ConvVAE` из `lab08_lib.py`, d = 8 |
| Данные | синтетические сцены 3×32×32 из `lab07_lib.py`, 4096 обучающих и 1024 тестовых, seed данных 7 |
| Режимы | A: β = 1; B: β = 8; оба — 30 эпох, разогрев KL 10 эпох, Adam 2·10⁻³, пакет 128 |
| Среда | Google Colab, Tesla T4, Python 3.13.16 |
| Библиотеки | torch 2.11.0+cu130; numpy 2.1.3; Pillow 11.3.0 |
| Итог | гипотеза подтверждена: реконструкция −4,36 дБ, R² −0,081, интерполяция −1,19 дБ; активных осей 6 → 3–4 |

## Результат

| Метрика | A (β = 1) | s | B (β = 8) | Δ | \|Δ\|/s | 2s | Класс по допуску |
| --- | ---: | ---: | ---: | ---: | ---: | :---: | --- |
| реконструкция, дБ | 25.788 | 0.494 | 21.427 | −4.361 | 8.82 | да | ухудшение (±1.0) |
| интерполяция, дБ | 22.703 | 0.335 | 21.516 | −1.187 | 3.54 | да | ухудшение (±1.0) |
| сэмплы, дБ | 22.633 | 0.180 | 22.167 | −0.467 | 2.59 | да | нейтрально (±1.0) |
| R² факторов | 0.926 | 0.011 | 0.845 | −0.081 | 7.64 | да | ухудшение (±0.05) |

![Лист сравнения: сэмплы AE и VAE β = 1, путь интерполяции при β = 1 и β = 8](artifacts/comparison.png)

- Активных осей (KL > 0,05 нат): при β = 1 — 6 на всех seed, при β = 8 — 3–4; суммарный KL падает с 9–10 до 2–2,5 нат на сцену.
- По пути интерполяции диск движется, а полоса смещается, не исчезая, в обоих режимах; при β = 8 диск заметно размыт.
- Для сэмплов критерий 2s и допуск дают разный ответ: изменение значимо по 2s, но меньше допуска.
- Без разогрева KL-члена схлопнулся seed 105 (реконструкция 16,88 дБ — уровень эталона «средняя картинка»); с разогревом — ни один.
- Сэмплы из N(0, I) у обычного автокодировщика — 12,71 дБ; из распределения μ на обучающих сценах — 20,21 дБ; у VAE β = 1 — 22,86 дБ.
- Демонстрационный вариант 1 воспроизведён в пределах 2s от методички, включая схлопывание seed 102.
- Дополнительный прогон в Engee 26.10.2-H1 (процессор, PyTorch 2.4.1): демо совпало с методичкой до последнего знака, вариант 7 — с Colab по всем классам; снимки консоли и вывод — в [engee/](engee/).

## Как повторить

1. Открыть [lab08.ipynb](lab08.ipynb) в Google Colab и выбрать среду «Графический процессор T4». Методичка рассчитана на Engee без GPU; та же библиотека проверена преподавателем и в Colab.
2. Выполнить ячейки сверху вниз. Ноутбук сам записывает библиотеки из `src/` ячейками `%%writefile` и сверяет их SHA-256, выполняет демо-вариант и вариант 7 и сохраняет `artifacts/` и `reports/environment.txt`.
3. После просмотра листа сравнения заполнить `VISUAL_CHECK` и выполнить ячейки до конца; последняя скачивает `lab08_results.zip`.
4. Обучение на GPU не побитово детерминировано: значения воспроизводятся в пределах разброса между seed, а не до последнего знака.
